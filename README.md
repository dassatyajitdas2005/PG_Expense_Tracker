# PG_Expense_Tracker
PG weekly bazar web...

A simple and responsive **PG Expense Tracker** web application built using **HTML5, CSS3, and JavaScript**.

This project helps users manage and track their daily, weekly, and monthly expenses while staying in a Paying Guest (PG). It provides an easy way to record expenses, monitor spending, and understand where money is being spent.

---

## 🚀 Features

- ➕ Add New Expense
- 🗑️ Delete Expense
- ✏️ Edit Expense
- 📅 Date-wise Expense Tracking
- 📊 Total Expense Calculation
- 🏷️ Expense Categories
- 💵 Amount Summary
- 🔍 Search Expenses
- 📱 Responsive Design
- 💾 Local Storage Support
